Rezka TV

Rezka TV — личное Android-приложение для просмотра каталога на Android TV и телефоне.

Политика конфиденциальности

Приложение может войти в ваш аккаунт Google только для одной цели: сохранять и синхронизировать ваши собственные данные приложения (избранное, историю и прогресс просмотра, выбранные озвучки, подписки на сериалы и настройки плеера) между вашими устройствами.

  • Используется только доступ drive.appdata / drive.file: приложение видит лишь собственный файл синхронизации в скрытой папке приложения на вашем Google Диске и не имеет доступа к другим вашим файлам.
  • Данные не передаются третьим лицам, не продаются и не используются для рекламы. Собственного сервера у приложения нет: данные хранятся только на ваших устройствах и на вашем Google Диске.
  • Выйти и отозвать доступ можно в настройках приложения или на странице myaccount.google.com/permissions. Удалить сохранённые данные можно в Google Диске: «Настройки → Управление приложениями → Rezka TV → Удалить скрытые данные».

Использование данных, полученных от API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.
